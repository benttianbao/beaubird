# 浙江鸟种离线预测页面

这是一个独立的本机页面，不会修改或启动 BeauBird 网站页面。

## 最简单的使用方法

1. 双击项目根目录的 `start-offline-prediction.cmd`。
2. 首次读取大型模型可能需要约十几秒；准备完成后，浏览器会自动打开 `http://127.0.0.1:3210`。
3. 页面已经选好默认模型。选择日期，再搜索并选择城市、区县或观鸟点。
4. 点击“开始预测”，查看该地点层级已完整物化的全部公共鸟种；低排名鸟种不会因概率阈值被隐藏。
5. 用完后关闭启动脚本所在的黑色窗口，离线服务就会停止。

页面只监听本机地址，只读访问 `data/prediction-models` 中包含完整正向预测结果的 `.sqlite` 模型。development 评估制品、OOF 缓存以及明确标记为 `test_only` 或内部构建的诊断模型不会出现在下拉框中。

参考范围表示相似日期和地点下完整清单的观察频率范围，不是“鸟一定在场”的绝对概率。省、市、区县和观鸟点层级可展示全部公共鸟种；为控制离线制品体积，H3 网格层仍只物化前 100 种。低支持鸟种可能显示“资料不足”，但仍保留排序和参考范围，避免把很低的候选直接过滤掉。

## 模型选择规则

- 默认优先选择 `zhejiang-v1-20260715.sqlite`。
- 如果默认文件不存在，优先选择已通过内置质量检查的完整模型，其次选择最新的完整实验模型。
- 模型切换后必须重新选择地点，避免把上一个模型的空间编号带到新模型。
- 未通过正式发布条件的模型会显示“实验版”，页面不会把它标为正式可用。

如需临时指定默认模型，可在启动前设置环境变量 `BEAUBIRD_OFFLINE_DEFAULT_MODEL`，值为模型文件名，不是完整路径。

## 安全边界

- 服务默认仅绑定 `127.0.0.1:3210`，不对局域网或互联网开放。
- 模型数据库以 SQLite 只读模式打开，并设置 `query_only`。
- 浏览器不能传入任意文件路径，只能选择启动时识别出的完整模型。
- 普通结果过滤敏感鸟种，不显示其精确地点。
- 正式网站入口 `start-site.cmd`、`server/site` 以及正式模型加载门均未修改。
