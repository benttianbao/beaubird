# BeauBird 前端「湿地晨雾」UI 换肤设计

**日期：** 2026-07-19  
**状态：** 已获用户确认（方案 C / 风格 1）  
**范围：** 网页主界面视觉升级，不影响功能  

---

## 1. 背景与目标

BeauBird 主界面（`index.html` + `style.css`）已具备侧栏工作台、分区色、面板与空状态等基础结构，整体偏「工具台」但视觉层次与氛围仍可加强。

**目标：** 在不改动任何业务功能的前提下，将页面气质升级为「清晨湿地、薄雾、青绿 + 暖金点缀」的专业观鸟工作台。

**成功标准：**

- 五个工具分区（监测 / 未解锁 / 预习 PPT / eBird / BirdReport）在视觉上明显焕新，但仍是同一产品。
- 所有查询、导出、监测、PPT 生成等行为与改前一致。
- 桌面宽屏、窄屏、Android WebView 无明显溢出、裁切或对比度崩溃。
- 不引入远程字体、CDN 或新运行时依赖。
- 老版本可通过 git tag 一键对照回滚。

---

## 2. 约束

### 2.1 必须保持不变

- 所有控件 `id`、按钮逻辑、导航 `data-target`、表单字段名。
- 结果区 DOM 语义结构与脚本渲染约定。
- `src/script/`、`script.js` 业务逻辑（本设计不要求改脚本）。
- 信息架构：侧栏导航 + 主内容多面板，不重排功能模块顺序。

### 2.2 允许改动

- 以 `style.css` 为主：`:root` token、背景、侧栏、面板、表单、按钮、空状态、阴影、圆角、过渡、响应式细化。
- `index.html`：仅更新 CSS cache-bust 查询参数（如 `style.css?v=`）；若装饰确需，最多增加 1～2 个纯装饰 class（优先不加）。
- 保留并完善 `@supports not (color: oklch(...))` 的 hex 回退，兼容旧 WebView。

### 2.3 明确不做

- 不引入远程资源（字体、图标 CDN、背景图 URL）。
- 不改业务文案含义、不重构 JS 模块。
- 不做深色主题切换（本方案为浅色「湿地晨雾」）。
- 不批量删除文件；不触碰密钥、`.env`、数据库。

---

## 3. 风格定案

**选定方向：** 湿地晨雾（方案 1）

**气质：** 清晨湿地、薄雾、青绿主调、暖金点缀；专业、清爽、略有氛围，避免插画手账感或重度霓虹深色台。

**未选方案（备忘）：**

- 林间深色专业台：对比度重做成本高，且偏离当前浅色用户习惯。
- 纸质田野笔记：偏温馨手账，与「专业工作台」定位不够贴合。

## 4. 视觉系统

### 4.1 色彩 token 演进

在现有 OKLCH token 上演进，不推倒重来。

| 角色 | 方向 |
|------|------|
| 页面底 `--bg` | 略偏青的雾面白；body 可叠加极淡径向光晕（顶偏暖、靠侧栏侧偏绿） |
| 表面 `--surface` / `--panel` | 近白雾面，与底有可感知但克制的分层 |
| 侧栏 `--sidebar-shell*` | 更深湿地绿纵向渐变；文字用浅色 ink / muted |
| 主色 `--primary` | 保持青绿，可略提饱和，不刺眼 |
| 暖金 | 用于监测强调、优先级面板边光、少量装饰高光（与 `--accent-monitor` 体系统一） |
| 五分区强调色 | 监测 / 未解锁 / PPT / eBird / BirdReport 保留独立色相，略统一饱和与明度 |
| 边框 / 分割 | 略柔，分区用 `section-accent` 混色 |
| 状态色 | success / warning / neutral / danger 保持可读，背景更干净 |

所有新增 token 必须在非 OKLCH 回退块中提供 hex 等价物。

### 4.2 形状与阴影

| 元素 | 建议 |
|------|------|
| 控件圆角 | 约 10px |
| 面板圆角 | 约 16px（`--radius-panel`） |
| 侧栏导航按钮 | 约 12px |
| 卡片阴影 | 轻浮起：短距离 + 低透明度 |
| 激活 / 跳转面板 | 略强阴影 + 边框强调色 |
| 主按钮 | 轻阴影；hover 上浮约 1px；active 按下 |
| 焦点环 | 沿用 section-accent 混色，保证可见 |

### 4.3 动效

- 过渡时间约 150–180ms，沿用 `--ease-out-quart`。
- 尊重 `prefers-reduced-motion: reduce`：关闭或缩短非必要 transform/动画。

## 5. 分区设计

### 5.1 侧栏

- 保持 sticky 左栏 + 主内容网格结构。
- 背景：更深纵向绿渐变；可用纯 CSS 模拟极弱质感（勿引图片）。
- Logo 徽章：圆角方块 + 内侧高光。
- 导航 active：左侧色条 + 半透明色块 + 图标底加强。
- 标题层级：kicker 更淡、h1 更实、subtitle 行高舒适。

### 5.2 主内容区

- 与侧栏交界干净；padding 略增呼吸感（在现有基础上微调，不大改栅格）。
- 面板：更大圆角、顶部「晨光」色条（柔和渐变，opacity 克制）。
- 优先级监测面板：顶区轻微暖向渐变，仍保持工具感。

### 5.3 表单与操作

- 控件壳层（controls shell）：略亮的内凹雾面（inset 高光可保留/加强）。
- input / select：表面对比略提高；focus 时边框 + 柔光环。
- 主按钮：主色填充 + 轻阴影 + hover 上浮。
- ghost 按钮：透明底 + 清晰描边，hover 淡填色。
- checkbox 控件：与分区强调色一致的弱底，不抢主按钮。

### 5.4 结果区、空状态、浮层

- 空状态：引导卡片感（图标圆、标题加粗、说明更淡）；虚线边可保留但更精致。
- stats：更像信息胶囊行，间距统一。
- message 的 loading / error 状态更分明。
- 详情浮层：backdrop 略加深雾感；面板圆角与阴影与主面板统一。

### 5.5 响应式与 Android

- 沿用现有断点（约 860 / 640 / 420）及 `embedded-android-app` 规则。
- 窄屏：**减弱**大阴影与多层渐变，避免糊成一团、降低 GPU 压力。
- 不改变窄屏信息架构与既有堆叠/导航行为。

## 6. 实现边界与文件

| 文件 | 改动 |
|------|------|
| `style.css` | 主战场：token、背景、侧栏、面板、按钮、表单、空状态、阴影、响应式 |

| `script.js` / `src/script/*` | 不改 |
| 测试 | 若断言仅依赖结构/文案，通常无需改；实现后跑相关 UI/脚本检查 |

## 7. Git 基线与回滚

**实现代码改动之前**必须：

1. 确认工作区中与本功能无关的脏文件不被误提交（如 `graphify-out/` 保持未跟踪）。
2. 在当前 HEAD 打 tag：`pre-ui-wetland-mist`，冻结换肤前的前端版本。
3. 在当前分支直接改样式，或可选开 `ui/wetland-mist` 分支（实现时与用户约定；默认可在当前功能分支上改）。

**回滚示例：**

```powershell
git checkout pre-ui-wetland-mist -- style.css index.html
```
